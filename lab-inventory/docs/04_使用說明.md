# 實驗室藥品器材耗材管理系統 — 使用說明（交接用）

> 臺北市立中山女子高級中學　教務處設備組
> 管理範圍：化學科、生物科實驗室的藥品、器材、耗材
> 系統組成：一份 Google 試算表 ＋ 試算表內的 Apps Script 程式 ＋ 手機盤點網頁

---

## 一、先認識系統

### 1. 東西放在哪裡

| 東西 | 位置 |
|---|---|
| 資料（品項、盤點紀錄…） | Google 雲端硬碟裡的試算表「實驗室藥品器材管理系統」 |
| 程式 | 試算表上方「擴充功能 → Apps Script」，共 6 個檔案（`01_基礎`～`06_補充查詢`） |
| 手機盤點網址 | 試算表「設定」工作表的「手機網頁網址」；或選單「開啟手機盤點網址」掃 QR code |
| 程式原始檔與文件 | GitHub：koala5566/lab-manager 的 `lab-inventory/` 資料夾 |

### 2. 工作表（下方分頁）

| 工作表 | 用途 | 誰來改 |
|---|---|---|
| 設定 | 學校名稱、學年度學期、核章欄、各下拉選單選項、清單分區的列印標題 | 您（每學期改學年度學期） |
| 品項 | **主檔**，每個藥品／器材／耗材一列 | 您（新增、移位、淘汰時） |
| 盤點紀錄 | 歷次盤點數字，一列＝某天、某品項、某存放處 | 程式寫入（必要時可手動修正） |
| 盤點表 | 本次盤點的工作底稿 | 程式產生，您填數量 |
| 需補充清單 | 低於安全存量的品項，自動更新 | 不用動 |
| 查詢 | 輸入條件，即時篩選品項 | 只填黃色格子 |
| 異動紀錄 | 新購、報廢、領用、移位（第二階段正式使用，目前可先手動記） | 您 |
| 實驗套組 | 每組器材與數量、共幾組；申報時會印出 | 您 |
| 玻片需求 | 永久玻片的需求數（第二階段使用） | 您 |
| 轉入檢查 | 舊資料轉入時的疑點紀錄 | 看完可刪 |

### 3. 選單「🧪 實驗室管理」

| 選單 | 做什麼 |
|---|---|
| 產生盤點表 | 選範圍、日期 → 產生盤點表 |
| 完成盤點（存入盤點紀錄） | 盤點表已填的數量存進盤點紀錄 |
| 開啟手機盤點網址 | 顯示 QR code，手機掃了就能開 |
| 列印藥品清單 | 藥品清單，最近 4 次盤點數量 |
| 列印器材耗材清單 | 依清單分區，每區一頁起 |
| 列印申報清單（期初／期末） | 申報用，每品項只印一次數量，附簽稿文字 |
| 列印藥品櫃標示 | 櫃外（橫式大字）／櫃內（直式小字） |
| 列印需補充清單 | 低於安全存量的品項 |
| 更新需補充清單 | 重建需補充清單、查詢的公式（通常不用按） |
| 重新計算最新數量 | 手動改過盤點紀錄後按 |
| 補上缺少的編號 | 新增品項沒有自動編號時按 |
| 套用工作表格式與下拉選單 | 「設定」的選項有增減後按 |

> 選單只在**電腦版**出現；手機 Google 試算表 App 看不到選單，手機請用「手機盤點網頁」。

## 二、每學期的工作流程

```
學期開始 ─→ 改「設定」學年度學期 ─→ 期初盤點 ─→ 申報（期初）
                                          │
期中盤點（視需要） ─────────────────────────┤
                                          │
學期末 ─→ 期末盤點 ─→ 申報（期末） ─→ 依需補充清單請購
```

### 1. 學期開始：改學年度學期
「設定」工作表 →「學年度學期」改成新的（例：`115-2`）。列印表頭會自動變「115學年度第2學期」。

### 2. 盤點

1. **產生盤點表**：選單「產生盤點表」
   - 範圍：建議「全部品項」（約 760 列），分幾天慢慢點；或選「教室」一間一間做
   - 日期：這次盤點的日期（分好幾天也用同一個日期）
   - 名稱：`115-2期初`、`115-2期末` 這種寫法（**申報時學期標示會依這個自動帶出**）
2. **填數量**（擇一或混用）
   - 電腦：「盤點表」黃色欄位「本次數量」
   - 手機：開手機盤點網頁 → 選教室、櫃別 → 輸入；一樣時按「＝上次」
3. **存檔**：選單「完成盤點」
   - 還沒點完 → 選「留在盤點表，下次繼續盤」
   - 點完了、剩下沒變 → 選「沿用上次數量一起存」
4. 存完後，「品項」的最新數量、「需補充清單」自動更新

**數量的寫法**
| 情況 | 本次數量 | 本次說明 |
|---|---|---|
| 一般 | `5.5` | （空白） |
| 有單位或混合 | `3箱+5串` | （空白） |
| 想分開寫 | `8` | `1.5粉狀 6.5固體顆粒` |

系統會從文字取出數字（`3箱+5串` → 3、`100g*2+50g` → 250），列印時照原文印。

**分處存放**：同一品項放好幾個地方（「品項」的「分處存放」有填），盤點表會每處一列，系統自動加總。

### 3. 申報（期初／期末）

1. 選單「列印申報清單（期初／期末）」
2. 選要申報的那次盤點 → 學期標示自動帶出（可改）→ 勾選清單 →「開啟列印頁」
3. 「🖨 列印」印出（或另存 PDF 附在公文）
4. 列印預覽上方「📄 簽稿文字」→ 複製 → 貼到公文系統的簽

### 4. 請購
看「需補充清單」或選單「列印需補充清單」。需要先在「品項」填「安全存量」才會有資料。

## 三、日常維護

### 新增品項
1. 「品項」最下面新增一列
2. 先選「類別」（藥品／器材／耗材），再填「品名」→ **編號自動產生**
3. 填好科別、清單分區、教室、櫃別、排序位置、單位；藥品填化學式、SDS、危險物品
4. 同一品項放好幾處：「分處存放」填 `化學準備室、生物準備室冰箱`（頓號分隔）
5. 第一次數量：下次盤點時會出現在盤點表；或直接在「盤點紀錄」加一列

### 品項移位
改「品項」的教室、櫃別、排序位置 → 重印那一櫃的標示。
（想留紀錄：「異動紀錄」加一列，類型「移位」）

### 品項淘汰／報廢
「品項」的「狀態」改「已淘汰」→ 不再出現在盤點表、清單、標示，但歷史紀錄保留。
（想留紀錄：「異動紀錄」加一列，類型「報廢」）

### 改錯盤點數字
直接改「盤點紀錄」那一列的「數量」或「數量說明」→ 選單「重新計算最新數量」。

### 備註與自己筆記
- 「備註」：**會印**在清單上
- 「自己筆記」：**不會印**，只給自己看

### 欄位不要改名、不要刪
各工作表第一列的欄位名稱，程式是靠名字找欄位的。可以調整欄寬、順序、新增自己的欄位，但**不要改名或刪除**原有欄位。

## 四、列印設定

所有列印都是：選單 → 出現「列印預覽」對話框 → 按上方「🖨 列印」（**不要用 Ctrl+P**）。

| 設定 | 值 |
|---|---|
| 目的地 | 印表機，或「另存為 PDF」 |
| 紙張 | A4 |
| 版面配置 | 直向（櫃外標示選**橫向**） |
| 更多設定 → 頁首和頁尾 | **取消勾選** |
| 更多設定 → 背景圖形 | **勾選** |

可在「設定」調整：學校名稱、學年度學期、核章欄（逗號分隔）、藥品清單列印次數（預設 4）、器材耗材清單列印次數（預設 1）、各清單分區的列印標題／副標題／存放地點／分處欄位。

## 五、常見問題

| 狀況 | 處理 |
|---|---|
| 看不到「🧪 實驗室管理」選單 | 重新整理，等 5～10 秒；手機 App 本來就沒有選單 |
| 手機網頁「很抱歉，目前無法開啟這個檔案」 | 手機瀏覽器登入了多個 Google 帳號；改用只登入這個帳號的瀏覽器 |
| 手機網頁「目前沒有盤點表」 | 先在電腦「產生盤點表」，手機按「重新整理」 |
| 手機輸入顯示「⚠ 沒存到」 | 網路問題，點那行字重試 |
| 「找不到工作表」「缺少欄位」 | 工作表或欄位名稱被改了，改回原名 |
| 日期或時間差一天、差 8 小時 | 「檔案 → 設定 → 時區」要是台北（程式開啟時會自動修正） |
| 新增品項沒有編號 | 類別、品名都要填；或選單「補上缺少的編號」 |
| 列印預覽只有 1 頁 | 用對話框上方「🖨 列印」按鈕 |
| 印出網址、日期 | 列印設定取消「頁首和頁尾」 |
| 需補充清單一直是空的 | 「品項」要填「安全存量」 |
| 需補充清單或查詢顯示錯誤 | 選單「更新需補充清單」重建（查詢條件要重填） |

## 六、備份

- Google 試算表會自動保存版本：「檔案 → 版本記錄 → 查看版本記錄」可回到任何時間點。
- 建議每學期申報後：「檔案 → 下載 → Microsoft Excel」存一份到電腦或學校共用資料夾。
- 申報清單另存 PDF，附在公文。

## 七、程式更新方法

1. 「擴充功能 → Apps Script」→ 點要換的檔案 → Ctrl+A 刪除 → 貼上新版 → Ctrl+S
2. **一定要重新部署**（否則手機網頁還是舊的）：「部署 → 管理部署作業」→「手機盤點」→ ✏️ →「版本：新版本」→「部署」
3. 回試算表按 F5

各檔案內容：

| 檔案 | 功能 |
|---|---|
| `01_基礎` | 選單、設定讀取、自動編號、最新數量、時區、格式 |
| `02_盤點` | 產生盤點表、完成盤點 |
| `03_手機盤點` | 手機網頁（盤點、查詢）、網頁入口 |
| `04_列印` | 藥品清單、器材耗材清單、申報清單、列印預覽 |
| `05_標示` | 藥品櫃標示 |
| `06_補充查詢` | 需補充清單、查詢、列印需補充清單 |

## 八、交接給下一位承辦人

1. **把試算表交給新承辦人**（擇一）：
   - **轉移擁有權**：雲端硬碟對試算表按右鍵 →「共用」→ 加入新承辦人為「編輯者」→ 再把他設為「擁有者」。
     （只有同一種帳號之間能轉，例如都是學校帳號；個人 Gmail 不能直接轉給學校帳號。）
   - **建立副本**（最保險）：先共用給新承辦人（檢視者即可）→ 新承辦人開啟後「檔案 → 建立副本」→ 副本就是他的，程式也會一起複製過去。
2. 新承辦人打開試算表 → 第一次使用任何選單功能時會要求授權，按「允許」（見 `03_安裝步驟.md` 第 2 步）。
3. **手機網頁要由新承辦人重新部署**（網頁是以部署者的身分執行）：「部署 → 新增部署作業 → 網頁應用程式 → 執行身分：我、存取：只有我自己」→ 新網址貼到「設定」的「手機網頁網址」。
4. 把這份使用說明、`03_安裝步驟.md` 一起交給新承辦人。
