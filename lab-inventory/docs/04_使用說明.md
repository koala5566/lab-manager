# 實驗室藥品器材耗材管理系統 — 使用說明（交接用）

> 臺北市立中山女子高級中學　教務處設備組
> 管理範圍：化學科、生物科實驗室的藥品、器材、耗材
> 系統組成：一份 Google 試算表 ＋ 試算表內的 Apps Script 程式 ＋ 手機盤點網頁

---

## 一、先認識系統

### 1. 東西放在哪裡

| 東西 | 位置 |
|---|---|
| 資料（品項、盤點紀錄…） | Google 雲端硬碟裡的試算表「實驗室藥品器材管理系統」 |
| 程式 | 試算表上方「擴充功能 → Apps Script」，共 11 個檔案（`01_基礎`～`11_統計報表`） |
| 手機盤點網址 | 試算表「設定」工作表的「手機網頁網址」；或選單「開啟手機盤點網址」掃 QR code |
| 程式原始檔與文件 | GitHub：koala5566/lab-manager 的 `lab-inventory/` 資料夾 |

### 2. 工作表（下方分頁）

| 工作表 | 用途 | 誰來改 |
|---|---|---|
| 首頁 | 儀表板：品項數、需補充、最近盤點、盤點進度、常用操作、分頁連結 | 自動 |
| 設定 | 學校名稱、學年度學期、核章欄、各下拉選單選項、清單分區的列印標題 | 您（每學期改學年度學期） |
| 品項 | **主檔**，每個藥品／器材／耗材一列 | 您（新增、移位、淘汰時） |
| 盤點紀錄 | 歷次盤點數字，一列＝某天、某品項、某存放處 | 程式寫入（必要時可手動修正） |
| 盤點表 | 本次盤點的工作底稿 | 程式產生，您填數量 |
| 需補充清單 | 低於安全存量的品項，自動更新 | 不用動 |
| 查詢 | 輸入條件，即時篩選品項 | 只填黃色格子 |
| 異動紀錄 | 新購、報廢、領用、移位（用「📦 品項 → 登記異動」寫入） | 程式寫入 |
| 請購清單 | 要買的東西：待處理 → 已請購 → 已到貨 | 對話框登記；狀態可直接改 |
| 準備事項 | 老師交代要準備的東西（一列＝一樣），待準備 → 已準備 → 已歸還 | 對話框、手機新增與打勾；也可以直接改 |
| 實驗排程 | 六間實驗室的使用登記：哪天、哪節、哪間、做什麼（實驗課、社團、自主學習…）、幾組 | 「登記使用」對話框；狀態可直接改 |
| 借用紀錄 | 借出、歸還 | 對話框登記 |
| 實驗套組 | 每組器材與數量、共幾組；申報時會印出 | 您 |
| 玻片需求 | 永久玻片的需求數（第二階段使用） | 您 |
| 轉入檢查 | 舊資料轉入時的疑點紀錄 | 看完可刪 |
| 操作紀錄 | 刪除偵測的紀錄（有資料被刪時才會出現） | 自動 |

## 二、每學期的工作流程

```
學期開始 ─→ 改「設定」學年度學期 ─→ 期初盤點 ─→ 申報（期初）
                                          │
期中盤點（視需要） ─────────────────────────┤
                                          │
學期末 ─→ 期末盤點 ─→ 申報（期末） ─→ 依需補充清單請購
```

### 1. 學期開始：改學年度學期
「設定」工作表 →「學年度學期」改成新的（例：`115-2`）。列印表頭會自動變「115學年度第2學期」。

### 2. 盤點

1. **產生盤點表**：選單「產生盤點表」
   - 範圍：建議「全部品項」（約 760 列），分幾天慢慢點；或選「教室」一間一間做
   - 日期：這次盤點的日期（分好幾天也用同一個日期）
   - 名稱：`115-2期初`、`115-2期末` 這種寫法（**申報時學期標示會依這個自動帶出**）
2. **填數量**（擇一或混用）
   - 電腦：「盤點表」黃色欄位「本次數量」
   - 手機：開手機盤點網頁 → 選教室、櫃別 → 輸入；一樣時按「＝上次」
   - 盤點表有篩選器（標題列的小漏斗），可以只看某個教室、櫃別，或「已盤」空白的
3. **存檔**：選單「完成盤點」，或手機網頁右上「✔ 完成盤點」
   - 還沒點完 → 選「留在盤點表，下次繼續盤」
   - 點完了、剩下沒變 → 選「沿用上次數量一起存」
4. 存完後，「品項」的最新數量、「需補充清單」自動更新

**數量的寫法**
| 情況 | 本次數量 | 本次說明 |
|---|---|---|
| 一般 | `5.5` | （空白） |
| 有單位或混合 | `3箱+5串` | （空白） |
| 想分開寫 | `8` | `1.5粉狀 6.5固體顆粒` |

系統會從文字取出數字（`3箱+5串` → 3、`100g*2+50g` → 250），列印時照原文印。

**分處存放**：同一品項放好幾個地方（「品項」的「分處存放」有填），盤點表會每處一列，系統自動加總。

### 3. 申報（期初／期末）

1. 選單「列印申報清單（期初／期末）」
2. 選要申報的那次盤點 → 學期標示自動帶出（可改）→ 勾選清單 →「開啟列印頁」
3. 「🖨 列印」印出（或另存 PDF 附在公文）
4. 列印預覽上方「📄 簽稿文字」→ 複製 → 貼到公文系統的簽

### 4. 請購
看「需補充清單」或選單「列印需補充清單」。需要先在「品項」填「安全存量」才會有資料。

## 三、日常維護

### 新增品項
**建議用選單「📦 品項 → 新增品項」**：表單填完按「新增」，編號自動產生；有填目前數量會一併記入盤點紀錄。

也可以直接在「品項」打：
1. 「品項」最下面新增一列
2. 先選「類別」（藥品／器材／耗材），再填「品名」→ **編號自動產生**
3. 填好科別、清單分區、教室、櫃別、排序位置、單位；藥品填化學式、SDS、危險物品
4. 同一品項放好幾處：「分處存放」填 `化學準備室、生物準備室冰箱`（頓號分隔）
5. 第一次數量：下次盤點時會出現在盤點表；或直接在「盤點紀錄」加一列

### 新購、領用、報廢、移位
選單「📦 品項 → 登記異動」→ 搜尋品項 → 選類型：
| 類型 | 會做什麼 |
|---|---|
| 新購 | 記異動紀錄；勾「同時更新目前數量」→ 最新數量＋數量 |
| 領用 | 記異動紀錄；勾「同時更新目前數量」→ 最新數量－數量 |
| 報廢 | 同上減數量；勾「整個品項淘汰」→ 狀態改「已淘汰」 |
| 移位 | 直接改品項的教室、櫃別、排序位置（藥品記得重印櫃標示） |

- 數量是文字寫法的（例：30公升+4.5）不會自動加減，會提醒您下次盤點時更新。
- 「同時更新目前數量」會在盤點紀錄加一筆「異動：新購」這類紀錄；同一天同一品項多次異動會自動合併成一筆，不會重複加總。

### 品項淘汰
「登記異動」選「報廢」並勾「整個品項淘汰」；或直接把「品項」的「狀態」改「已淘汰」→ 不再出現在盤點表、清單、標示，但歷史紀錄保留。

### 改錯盤點數字
直接改「盤點紀錄」那一列的「數量」或「數量說明」→ 選單「重新計算最新數量」。

### 備註與自己筆記
- 「備註」：**會印**在清單上
- 「自己筆記」：**不會印**，只給自己看

### 欄位不要改名、不要刪
各工作表第一列的欄位名稱，程式是靠名字找欄位的。可以調整欄寬、順序、新增自己的欄位，但**不要改名或刪除**原有欄位。

## 四、列印設定

所有列印都是：選單 → 出現「列印預覽」對話框 → 按上方「🖨 列印」（**不要用 Ctrl+P**）。

| 設定 | 值 |
|---|---|
| 目的地 | 印表機，或「另存為 PDF」 |
| 紙張 | A4 |
| 版面配置 | 直向（櫃外標示選**橫向**） |
| 更多設定 → 頁首和頁尾 | **取消勾選** |
| 更多設定 → 背景圖形 | **勾選** |

可在「設定」調整：學校名稱、學年度學期、核章欄（逗號分隔）、藥品清單列印次數（預設 4）、器材耗材清單列印次數（預設 1）、各清單分區的列印標題／副標題／存放地點／分處欄位。

## 五、常見問題

| 狀況 | 處理 |
|---|---|
| 看不到「🧪 實驗室管理」選單 | 重新整理，等 5～10 秒；手機 App 本來就沒有選單 |
| 手機網頁「很抱歉，目前無法開啟這個檔案」 | 手機瀏覽器登入了多個 Google 帳號；改用只登入這個帳號的瀏覽器 |
| 手機網頁「目前沒有盤點表」 | 先在電腦「產生盤點表」，手機按「重新整理」 |
| 手機輸入顯示「⚠ 沒存到」 | 網路問題，點那行字重試 |
| 「找不到工作表」「缺少欄位」 | 工作表或欄位名稱被改了，改回原名 |
| 日期或時間差一天、差 8 小時 | 「檔案 → 設定 → 時區」要是台北（程式開啟時會自動修正） |
| 新增品項沒有編號 | 類別、品名都要填；或選單「補上缺少的編號」 |
| 列印預覽只有 1 頁 | 用對話框上方「🖨 列印」按鈕 |
| 印出網址、日期 | 列印設定取消「頁首和頁尾」 |
| 需補充清單一直是空的 | 「品項」要填「安全存量」 |
| 需補充清單或查詢顯示錯誤 | 選單「更新需補充清單」重建（查詢條件要重填） |

## 六、資料安全與備份

### 自動備份
- **每週五 17:00** 自動複製整份試算表（含程式）到雲端硬碟「**實驗室管理備份**」資料夾。
- **每次「完成盤點」後**也會自動備份一份。
- 只保留最近 **10 份**，較舊的會移到雲端硬碟垃圾桶（30 天內還能救回）。
- 要馬上備份：🔧 維護 → 立即備份。

### 從備份還原
1. 雲端硬碟 →「實驗室管理備份」→ 找到想要的日期 → 打開。
2. 小範圍救資料：從備份複製那幾列，貼回正式試算表。
3. 整份換掉：把備份檔改名成正式名稱、原本的改名或刪除；**記得重新部署手機網頁**並更新「設定」的手機網頁網址。

### 版本記錄（Google 內建）
「檔案 → 版本記錄 → 查看版本記錄」可以回到任何時間點，適合「剛剛改錯」的情況。

### 資料保護（警告模式）
改到下列地方時，會先跳出「確定要編輯嗎？」，按「確定」就能改，只是多一道確認：
- 整張：盤點紀錄、設定、首頁、需補充清單
- 查詢：黃色條件格以外
- 盤點表：黃色的本次數量、本次說明以外
- 品項：第 1 列欄位名稱、編號、最新盤點日期、最新數量、最新數量說明

### 刪除偵測
盤點紀錄或品項被刪列、重要分頁被刪時：右下角跳出「⚠ 偵測到資料被刪除」，並記在「操作紀錄」分頁。
誤刪請馬上按 **Ctrl+Z**；來不及就用版本記錄或備份還原。
**品項不要刪列**，要淘汰請把狀態改成「已淘汰」。

### 共用設定（請自己檢查一次）
雲端硬碟對試算表按右鍵 →「共用」→ 確認「一般存取權」是「**限制**」（只有加入的人能開），不要設成「知道連結的任何人」。
手機網頁部署的存取權維持「**只有我自己**」。

## 七、程式更新方法

1. 「擴充功能 → Apps Script」→ 點要換的檔案 → Ctrl+A 刪除 → 貼上新版 → Ctrl+S
2. **一定要重新部署**（否則手機網頁還是舊的）：「部署 → 管理部署作業」→「手機盤點」→ ✏️ →「版本：新版本」→「部署」
3. 回試算表按 F5

各檔案內容：

| 檔案 | 功能 |
|---|---|
| `01_基礎` | 選單、設定讀取、自動編號、最新數量、時區、格式 |
| `02_盤點` | 產生盤點表、完成盤點 |
| `03_手機盤點` | 手機網頁（盤點、查詢）、網頁入口 |
| `04_列印` | 藥品清單、器材耗材清單、申報清單、列印預覽 |
| `05_標示` | 藥品櫃標示 |

## 九、請購、實驗準備、借用（工作流程）

### 請購
1. 老師說要買東西 →「🛒 請購 → 新增請購需求」：能搜尋到現有品項就點選（到貨會自動加庫存）；新東西直接打品名。
2. 定期「🛒 請購 → 從需補充清單加入」：低於安全存量的自動加入，數量＝補到安全存量。
3. 要送請購時「🛒 請購 → 列印請購清單」；送出後在「請購清單」把狀態改「**已請購**」、填請購日期。
4. 東西到了「🛒 請購 → 到貨入庫」→ 勾選 → 狀態自動改「已到貨」；有對應品項的會自動登記新購並加庫存；沒建檔的新東西，用「📦 品項 → 新增品項」建檔。
5. 「需要日期」7 天內還是待處理的，會標紅。

### 實驗準備
1. 在「**實驗套組**」工作表建好每個實驗的器材：套組名稱、課程年級、組數（預設）、品名、每組數量、每組數量說明（例：8片）、存放位置。
   - 「編號」可以空白，系統會用品名去對「品項」。品名要和品項一樣才對得到。
   - 每組數量的單位（例：片）和品項的單位（例：盒）不同時，準備單會提醒「單位不同，請自行確認」，不會誤判不足。
2. 老師告訴您實驗時間 →「🗓 實驗室使用 → 登記使用」，用途類型選「實驗課」，登記時就會告訴您器材夠不夠（見第十一節）。
3. 實驗前「🗓 實驗室使用 → 列印實驗準備單」，選日期範圍 → 每個實驗一張，照單準備、打勾；實驗後回收再打勾「歸還」。
4. 「實驗排程」的狀態改「已準備」「已歸還」；3 天內還沒準備的會標橘色。

### 借用
- 「📦 品項 → 借出登記」→ 搜尋品項、數量、借用人、預計歸還日。
- 還回來：「📦 品項 → 歸還登記」→ 勾選。
- 借出不改變庫存數量；盤點時請把借出去的也算進去。
- 逾期未還在「借用紀錄」標紅，首頁也會顯示。

## 十一、實驗室使用登記、門口海報、本週課表

### 登記
「🗓 實驗室使用 → **登記使用（一週課表）**」：
1. 上面選**實驗室**、**週次**（◀ ▶ 換週）、**用途類型**（實驗課、補做實驗、社團、自主學習、專題研究、老師借用、借用教室、考試、研習、其他）。
2. **內容**：實驗課／補做實驗從「實驗套組」選（找不到選「其他（自行輸入）」）；其他類型直接打，例如「化學研究社」「專題：酵素活性」。
3. 填**教師／負責人**、**預設班級**（例：101）。
4. 在下面課表**點空格**（變藍色）＝要登記的時段；每一格裡可以改班級（例：3-4 節 101、5 節 102）。
   有顏色的格子是已經有人登記的。
5. 同一班連續的節次會自動合併成一筆（3、4 節 →「3-4」）；中午自己一筆。
6. 每週固定的（例如社團每週一中午）→ 填「**每週重複到**」某一天，就會每週登記到那天。
7. 按「登記」。同一間、同一天、同一節已經有人登記時，會列出來並問「仍要登記」嗎（撞堂提醒）。

登記存在「實驗排程」工作表，可以直接改或刪（例：改日期、取消 → 狀態改「取消」就不會出現在課表上）。
節次欄可以寫「3-4」「5」「午」「1,2」。

### 看使用情形
「🗓 實驗室使用 → **六間實驗室使用一覽**」：單日（六間 × 各節）／整週；現在這一節會標紅框；也可以按「🖨 列印」。
手機網頁多了「**使用**」分頁，可以隨時看。

### 列印（門口）
- 「**列印門口海報（A4 橫式）**」：選實驗室（或全部六間）、週次 → 這週每個「實驗課／補做實驗」印一張。
  - 年級：取「實驗套組」的「課程年級」；沒填就從班級推（101 → 高一）。
  - **講義 QR code**：在「實驗套組」加一欄「**講義連結**」，填那個實驗的講義網址（雲端硬碟要設「知道連結的人可檢視」）；有填才會印 QR code。
- 「**列印本週課表（A4 直式）**」：選實驗室（或全部六間，每間一頁）、週次 → 每一節的實驗名稱、班級、授課教師，依用途類型上色。週末有登記才會多印週六、週日。

### 在「設定」可以改的
| 設定欄 | 內容 |
|---|---|
| 上課教室 | 六間實驗室（登記、一覽、課表用這份清單） |
| 節次／開始／結束 | 第1節 08:10–09:00 …中午 12:00–13:10 …第7節 15:20–16:10（依學生手冊）；時間改了這裡改就好 |
| 用途類型／顏色 | 類型名稱與課表顏色（顏色用 #RRGGBB，例：#D2E3FC） |
| 班名 | 仁、義、禮…廉（照班序 01～21）。課表、海報的班級都用班名顯示；登記時打「213」也會顯示成「二敬」，並依班序排列 |
| 安全注意事項（A 欄項目） | 印在門口海報上，每一條用「｜」隔開 |

### 匯入老師排的課表
負責老師會用 Excel 排整學期的實驗室課表（每週一塊、第 1～7 節，格子寫「二敬-仲文」）。
1. 「檔案 → 匯入 → 上傳」老師的 Excel →「插入新工作表」。工作表名稱要有「化一」「化二」「生一」…才會自動對到實驗室（也可以在匯入時自己選）。
2. 「🗓 實驗室使用 → 匯入實驗室課表」→ 勾選工作表、確認實驗室、選「從哪天開始」→ 預覽 → 確定匯入。
3. 格子內容會自動分類：
   | 老師寫的 | 登記成 |
   |---|---|
   | 二敬-仲文 | 實驗課，班級「二敬」、教師 仲文（實驗名稱之後補） |
   | 多元選修 | 多元選修 |
   | 研究方法、專題 | 專題研究 |
   | ○○考、模擬考、學測 | 考試 |
   | ○○放假、補假 | 放假 |
   | 其他（休業式…） | 其他 |
   合併儲存格＝連續好幾節（例：期中考第 1-7 節）。年份打錯（跨年寫成同一年）會自動修正並提醒。
4. **實驗名稱**：預覽時每週可以填一次；也可以之後在「實驗排程」的「實驗名稱」欄補。
5. 老師改版了就再匯入一次：只會換掉「從同一張工作表匯入、且在從哪天開始以後」的登記；自己用「登記使用」登記的不動；已經補上的實驗名稱、組數、狀態、備註會保留（同實驗室、日期、節次、班級對得上的話）。
6. 老師的課表和自己登記的撞堂時，預覽會列出來。

## 十二、準備事項（老師交代的待辦）

老師口頭說、或寫便條紙要準備的東西，用這個記下來，不怕忘。

### 新增
「🗓 實驗室使用 → 📝 新增準備事項（老師交代的）」，或手機網頁「待辦」分頁 →「＋ 新增」：
1. **哪天要用**：預設是下一個上課日。
2. **對到當天的課**（可不選）：列出那天登記的課，選了會自動填好實驗室、節次、班級、老師。
3. **要準備的東西**：打品名會跳出品項讓您點（會顯示存放位置、庫存，數量不夠會提醒）；品項裡沒有的東西（冰塊、報紙…）直接打就好。一次可以按「＋ 再一樣」加好幾樣。
4. **備註**：便條內容、「老師自己來拿」之類。
5. 按「儲存」。表單會留著同一天，可以接著加下一堂課的。

### 待辦清單
「🗓 實驗室使用 → 📝 準備事項待辦清單」或手機「待辦」分頁：
- 依日期排；**過期沒準備的紅字**、今明兩天橘字。
- **打勾＝已準備**（打錯了再點一次就取消打勾）；用完收回可以在「最近完成」按「**已歸還**」。
- 不用準備了按「取消」，再按一次「確定取消？」。
- 首頁第二排「待準備事項」卡片會顯示還有幾項、有沒有過期。

### 列印
「🗓 實驗室使用 → 列印準備事項」→ 選日期範圍 → 依日期分表，有「準備」「歸還」打勾欄、存放位置與庫存。

### 直接改
「準備事項」工作表可以直接改日期、數量、狀態（待準備／已準備／已歸還／取消）。最左邊隱藏的「ID」欄請不要改。
