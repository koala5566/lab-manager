# 實驗室藥品器材耗材管理系統 — 整體設計說明（草案 v0.1）

> 臺北市立中山女子高級中學 教務處設備組
> 適用：化學科、生物科實驗室之藥品、器材、耗材
> 狀態：**等待承辦人確認中，尚未撰寫程式**

---

## 一、名詞解釋（先看這裡）

| 名詞 | 白話說明 |
|---|---|
| Google 試算表 | 雲端版的 Excel，存在 Google 雲端硬碟，電腦、手機都能開。 |
| 工作表 | 試算表下方的分頁標籤（例如「品項」「盤點紀錄」），等於 Excel 的工作表。 |
| Apps Script | Google 內建的小程式工具。從試算表上方「擴充功能 → Apps Script」打開，把程式碼貼進去，就能在試算表多出自訂功能。 |
| 自訂選單 | 程式安裝好後，試算表上方會多一個「🧪 實驗室管理」選單，點選即可執行功能（只在電腦版出現）。 |
| 網頁應用程式（Web App） | 用同一份 Apps Script 產生的一個網址。手機用瀏覽器打開這個網址就能盤點、查詢。設定成「只有我自己能開」，所以不需另外做登入。 |
| 主檔 | 每個品項只登記一次基本資料（名稱、位置、單位…）的總表。 |
| 編號 | 每個品項的「身分證字號」，系統用它把主檔、盤點、異動資料串起來，一旦給了就不要改。 |
| 下拉選單（資料驗證） | 儲存格只能從清單中選，避免同一個教室寫成「化1」「化一」兩種。 |

## 二、整體架構

```
┌─────────────── Google 試算表（資料都在這裡） ───────────────┐
│ 設定 │ 品項 │ 盤點紀錄 │ 盤點表 │ 需補充清單 │ 查詢 │ 異動紀錄 … │
└──────────────────────────────────────────────────────────────┘
          ▲                          ▲
          │ 電腦：自訂選單            │ 手機：網頁應用程式（瀏覽器開網址）
          │  ・產生盤點表             │  ・選教室／櫃別 → 逐項輸入數量
          │  ・完成盤點(存檔)         │  ・查詢品項
          │  ・列印清單 / 櫃標示      │
          └──────── Apps Script（程式） ────────┘
```

**為什麼手機要用「網頁應用程式」？**
Google 試算表的手機 App **不會顯示自訂選單、也不能按按鈕執行程式**，這是 Google 的限制。所以手機盤點改用一個專屬網頁：大字、大輸入框、依櫃別分頁，存檔直接寫回試算表。

**為什麼列印用網頁（HTML）而不是直接印試算表？**
試算表的列印只能「每頁重複表頭」，**做不到每頁頁尾都印核章欄**。改由程式產生列印專用網頁，用 Chrome 列印（或另存 PDF）時：
- 每頁自動重複表頭（學校名稱、學年度學期、更新日期、欄位名稱）
- 每頁頁尾自動出現「實驗室管理員／設備組長／主任／校長」核章欄
- 固定 A4 直式（藥品清單、器材清單）

### 2. 盤點紀錄

一列 = 一次盤點 × 一個品項 × 一個存放處。

| 欄位 | 說明 | 範例 |
|---|---|---|
| 盤點日期 | 實際日期（系統內存西元，畫面與列印顯示民國） | 115/08/26 |
| 盤點名稱 | 方便辨認 | 115-1期初 |
| 編號 | 對應品項主檔 | 生器0012 |
| 品名 | 程式順手帶入，方便閱讀（以主檔為準） | 50mL 燒杯 |
| 存放處 | 單一存放時空白；分處存放時填該處 | 生一 |
| 數量 | **數字**，計算加總、安全存量比對都用它 | 98 |
| 數量說明 | 文字，**列印時照原樣印**；沒填就印數字 | 3箱+5串 |
| 登錄時間 | 程式自動填 | 2026/09/29 10:12 |

**加總規則**：列印與「最新數量」使用同一日期、同一編號所有存放處的「數量」加總。
**數量說明與加總**：分處存放時，若各處都沒有數量說明，就印加總數字；只要有一處有說明，就印成「生一 98、生二 98」這樣逐處列出（此規則可再調整）。

### 列印格式（比照目前格式）

**藥品清單**（A4 直式）
- 表頭：臺北市立中山女子高級中學／化學與生物實驗室藥品清單／115學年度第1學期／更新日期 115.08.26
- 欄位：序號｜中文名稱｜化學式｜教室｜存放位置（櫃）｜存放位置（排序）｜最近 4 次盤點數量（欄名顯示盤點日期）｜備註
- 序號於列印時依排序自動產生（1、2、3…），不需人工維護
- 每頁頁尾：實驗室管理員｜設備組長｜主任｜校長 核章欄

**器材與耗材清單**（A4 直式，依清單分區各自成頁）
- 表頭：學校名稱＋各分區原標題（例：3樓化學實驗室清單 — 器材區物品與耗材，存放地點：化學準備室）
- 欄位：序｜存放位置｜品項｜單位｜最近 N 次盤點數量（預設 5 次，比照目前）｜備註
- 分處存放的分區（生物器材、生物耗材）：比照目前格式，列出各存放處數量＋總數量
- 「自己筆記」不列印

**藥品櫃標示**（比照目前「藥品櫃內標示」「藥品櫃外」）
- 每櫃一個表格：左欄「第1排…第5排」，每排依排序位置橫向列出品名，下一行為化學式
- 櫃外版：右上角印教室全名（如「化學準備室」）與更新日期，字體放大，一櫃一頁（A4 橫式）
- 從主檔自動產生，改了主檔重印即可，不會再出現標示與清單不一致的情形

### 數量轉換規則
| 舊寫法 | 數量（數字） | 數量說明（照印） |
