## 二、部署與修復

- [ ] **1.** 「部署 → 管理部署作業」→ ✏️ →「版本：新版本」→「部署」
- [ ] **2.** 回試算表 F5 →「🔧 維護 → 首頁、美化與資料保護（一次設定）」
      ✅ 這一步會把「實驗排程」「準備事項」的「節次」欄改成純文字，**已經變成日期的（例如 3/4、1/7）自動改回「3-4」「1-7」**
- [ ] **3.** 打開「實驗排程」看新教室那幾筆的「節次」✅ 顯示「3-4」這種，不是日期

## 三、試用：要先買的準備事項

- [ ] **4.** 網頁「＋」新增準備事項 → 打東西 → 勾「🛒 要先買（也加進請購清單）」→ 儲存
      ✅ 提示「…項加進請購清單」；「請購清單」多一列，備註是「準備事項 T…」、用途寫哪天哪一堂課
- [ ] **5.** 待辦清單上那一項顯示「🛒 請購：待處理」；請購清單狀態改「已請購」、到貨入庫後，這裡會跟著變「已請購」「已到貨」
- [ ] **6.** 已經登記的準備事項，後來才發現要買：在那一項按「🛒 要先買」就會加進請購清單（電腦的待辦清單也有這個按鈕）

## 原因說明（給之後維護的人）
Google 試算表會把「3-4」「1-7」這種文字自動當成日期（3月4日、1月7日）。新教室登記時常是連續兩節，存成「3-4」就被轉掉了，讀出來變成奇怪的時間，也對不到當天的課。
現在節次欄一律設成純文字，讀取時遇到被轉成日期的也會自動轉回來。
