## 二、改了什麼、怎麼用

### 試算表（🔧 維護、🖨 列印、🗓 實驗室使用）

| 代號 | 功能 | 什麼時候用 |
|---|---|---|
| **D1** 📦 封存舊資料 | 選一個日期 → 這天以前的實驗排程、已完成的準備事項、已到貨／取消的請購、已歸還的借用，搬到「…_封存」工作表（同一個檔案）。**搬之前自動做永久備份**；還沒準備的事項不搬；只能封存 30 天以前的；盤點紀錄不搬（統計要用）。先顯示各表要搬幾筆再確認 | 一年後、或覺得網頁變慢時；建議每學年一次，日期選「上學期開學日」 |
| **D2** 🏷 教室改名 | 選舊名稱、填新名稱 → 設定、實驗排程、準備事項（含封存表）一次改好；可勾「品項的存放教室也一起改」。新名稱已經存在＝合併。也會列出「資料裡有、設定裡沒有」的舊名稱，可以順便修好 | 教室改名、或發現課表有一間對不上時 |
| **D3** 匯入課表不重寫 | 重新匯入老師課表時：同一堂課**原地更新**（已填的實驗名稱、組數、狀態、備註都保留）；新的加在最後；課表上沒有了的**改成「取消」不刪除**（備註寫原因，之後又出現會自動恢復）；**手動登記的一格都不動**、也不重新排序 | 每次匯入都自動這樣，不用設定 |
| **D6** 🔒 嚴格保護／🔓 警告模式 | 嚴格：盤點紀錄、設定、首頁、需補充清單、品項的自動欄位，**只有你能改**，其他共用的人改不了（你自己、網頁、選單照常）。警告模式＝現在的樣子（會先問）。重新執行「一次設定」也會維持你選的模式 | 開放同仁編輯試算表時切嚴格；只有你用時維持警告模式 |
| **C4** 🖨 櫃子 QR Code 貼紙 | 「🖨 列印 → 櫃子 QR Code 貼紙」→ 選教室 → 每個櫃子一張（約 4.5×5.5 公分），用「品項」的教室＋櫃別。QR Code 在系統裡產生，不用連外部網站 | 印出來剪下、貼在櫃門上 |

### 網頁

| 代號 | 功能 | 怎麼用 |
|---|---|---|
| **B3** 自動同步 | 每分鐘檢查一次試算表有沒有被改過（別台手機、電腦、直接改試算表都算），有就自動重新整理，提示「🔄 已同步最新資料」。正在打字、開著視窗、盤點中、還有資料沒上傳時不會打擾 | 不用設定 |
| **C3** 字體大小 | 「更多 → 字體大小」：標準／大／特大，記在這台裝置 | 準備室光線差、不想戴眼鏡時 |
| **C4** 掃 QR Code | 手機相機掃櫃子上的 QR Code → 打開網頁、直接列出**這一櫃的品項**（數量、位置）；按「**盤點這一櫃**」直接跳到盤點那一櫃 | 找東西、盤點時 |
| **C5** 拖曳換時段 | 平板、電腦的課表（整週或單日）：**按住課程拖到別的格子** → 確認「從…移到…」→ 移過去；那個時段有課會先告訴你，要按「還是要移」才會重疊；同一堂課的準備事項**跟著移**；提示上有「復原」。平板要**長按約半秒**再拖（直接滑是捲動畫面）。放假整天的不能拖 | 調課、補課時 |

## 三、試試看

- [ ] **4.**「🔧 維護 → 🏷 教室改名」打開看看有沒有列出「不在設定裡」的教室（有的話可以順便修）

## 小提醒

- 封存後，網頁課表往前翻到封存的日期會是空的；資料在「實驗排程_封存」工作表裡。
- 匯入課表後，新增的課在「實驗排程」的最下面（不再自動依日期重排）。要看順序可以用「資料 → 建立篩選器」排序，不影響系統。
- 掃 QR Code 的人要登入有權限的 Google 帳號（現在只有你）。
- 自動同步每分鐘問一次，Google 的每日額度用不完，不用擔心。
