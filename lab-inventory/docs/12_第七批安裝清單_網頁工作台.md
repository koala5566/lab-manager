# 第七批安裝清單：網頁工作台（手機、平板、電腦共用的新網頁）

> 約 5 分鐘。照順序做，做完打勾 ✅。

## 一、貼程式（2 個檔案）

「擴充功能 → Apps Script」。
**換掉**：點檔名 → Ctrl+A → Delete → Ctrl+V → Ctrl+S
**新增**：「＋」→「指令碼」→ 打檔名 → 刪掉 `function myFunction() { }` → 貼上 → Ctrl+S

| ✅ | 檔案 | 做法 | 貼完最後一行的行號 |
|---|---|---|---|
| ☐ | `03_手機盤點` | 換掉 | 447 |
| ☐ | `16_網頁工作台` | 新增 | 1238 |

- [ ] 左邊總共 **16 個檔案**
- [ ] `16_網頁工作台` 很長（1238 行），貼完**一定要**捲到最底看行號，確定整份都貼到

## 二、重新部署

- [ ] **1.** 「部署 → 管理部署作業」→「手機盤點」→ ✏️ →「版本：**新版本**」→「部署」
      （網址不會變，手機原本的書籤、主畫面捷徑都能繼續用）

## 三、試用

- [ ] **2. 手機**：打開原本的手機網頁（重新整理）✅ 變成新版：下面有「今天／課表／待辦／盤點／更多」五顆按鈕
  - 今天：現在第幾節、哪幾間在上課；今天和下一個上課日的課；待準備
  - 點任一堂課 → 從下面滑出詳細（器材夠不夠、補實驗名稱、準備事項）
  - 右下角 ＋ → 新增準備事項（先點「哪一堂課」，打品名會跳出品項）
  - 盤點：一次一項，−／＋，「存好，下一項」
  - 更多 → 外觀：跟著系統／淺色／深色
- [ ] **3. 平板、電腦**：用瀏覽器開同一個網址 ✅ 左邊是側邊選單；「今天」是儀表板（數字卡片、六間實驗室現在、各節使用、待準備、需補充）
  - 課表點一堂課，詳細顯示在右邊
- [ ] **4. 加到主畫面**（像 App 一樣）
  - iPhone／iPad：Safari 開網址 → 分享 → 「加入主畫面」
  - Android：Chrome 開網址 → 右上「⋮」→「加到主畫面」

## 舊版網頁
新版有問題時，網址後面加 `?page=old`（例如 `…/exec?page=old`）就是舊版；「更多 → 舊版網頁」也可以開。
新版確定都沒問題後，再告訴我，我幫您把舊版的程式刪掉，減少維護。
