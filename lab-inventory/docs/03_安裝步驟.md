# 安裝步驟（依序完成；日後交接可照此重建）

## 第 1 步：建立試算表

1. 把 `data/新系統初始資料.xlsx` 上傳到 Google 雲端硬碟。
2. 在檔案上按右鍵 →「開啟工具 → Google 試算表」。
3. 上方「檔案 → 儲存為 Google 試算表」，之後都用這份。
4. 改名為「實驗室藥品器材管理系統」。
5. **檢查時區**：「檔案 → 設定」→「時區」選 **(GMT+08:00) 台北**，按「儲存設定」。
   （時區不對，日期可能差一天。）

---

## 第 2 步：貼上基礎程式

**做什麼**：試算表上方出現「🧪 實驗室管理」選單；新增品項自動給編號；可重新計算最新數量；套用下拉選單與格式。

### 貼程式

1. 在試算表上方點「**擴充功能 → Apps Script**」，會開新分頁（Apps Script 編輯器）。
2. 左上角專案名稱「未命名的專案」點一下，改成「實驗室管理系統」。
3. 左邊「檔案」下有一個 `程式碼.gs`（或 `Code.gs`）。點它右邊的「⋮ → 重新命名」，改成 `01_基礎`。
4. 把右邊編輯區原有的 `function myFunction() { }` **全部刪掉**。
5. 打開 `apps-script/01_基礎.gs`，**全部複製**（Ctrl+A、Ctrl+C），貼到編輯區（Ctrl+V）。
6. 按上方 💾「儲存專案」（或 Ctrl+S）。

### 第一次執行（授權）

1. 編輯區上方有個下拉選單（寫著某個函式名稱），選 **`setupSheets`**，按「▶ 執行」。
2. 跳出「需要授權」→「審查權限」→ 選您的 Google 帳號。
3. 出現「Google 尚未驗證這個應用程式」→ 點左下「**進階**」→「**前往「實驗室管理系統」(不安全)**」→「**允許**」。
   - 這是您自己寫、只存取這份試算表的程式，所以 Google 會這樣提醒，可以放心。
4. 下方「執行記錄」出現「**執行完畢**」就完成了。

### 確認成功

1. 回到試算表分頁，按 F5 重新整理。
2. 上方出現「**🧪 實驗室管理**」選單（載入要幾秒鐘），目前裡面有 3 項（之後每完成一步會自動多出新功能）：
   - 重新計算最新數量
   - 補上缺少的編號
   - 套用工作表格式與下拉選單
3. 點「重新計算最新數量」，右下角出現「已更新 723 個品項的最新數量」。
4. 到「品項」最下面新增一列測試：類別選「藥品」、品名打「測試」→ 編號欄自動出現「藥0245」、狀態自動變「使用中」。確認後把這一列刪掉（右鍵列號 → 刪除列）。

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 看不到選單 | 重新整理試算表；等 5 秒；還是沒有，回 Apps Script 確認已儲存 |
| 「找不到工作表『○○』」 | 分頁名稱被改過，改回原名 |
| 「缺少欄位：○○」 | 第一列標題被改過或刪掉，改回原名 |
| 新增品項沒有自動編號 | 要先選「類別」再打品名（或反過來都可以，兩個都有才會編）；或從選單執行「補上缺少的編號」 |

## 第 3 步：盤點功能（電腦版）

**做什麼**：選單多出「產生盤點表」「完成盤點（存入盤點紀錄）」。

### 貼程式

1. 試算表「擴充功能 → Apps Script」。
2. 左邊「檔案」旁的「＋」→「指令碼」，名稱打 `02_盤點`（會自動變成 `02_盤點.gs`）。
3. 把新檔案裡原有的 `function myFunction() { }` 刪掉。
4. 複製 `apps-script/02_盤點.gs` 全部內容貼上，Ctrl+S 儲存。
5. **`01_基礎` 不要動**，兩個檔案要同時存在。

### 第一次執行

1. 回到試算表，按 F5 重新整理。
2. 選單「🧪 實驗室管理 → 產生盤點表」。
3. 第一次會再要求授權一次（因為新增了「對話框」功能），照第 2 步的方式按「允許」。授權完再點一次「產生盤點表」。

### 試用（確認成功）

1. 「產生盤點表」→ 盤點範圍選「清單分區」「生物器材」→ 日期、名稱用預設 → 按「產生盤點表」。
2. 自動跳到「盤點表」分頁，看到：
   - 每個品項分成「生物實驗室一」「生物實驗室二」兩列
   - 「上次日期」115.08.26、「上次數量」有數字
   - 「本次數量」「本次說明」兩欄是**黃色**
3. 在第一列「本次數量」打個數字 → 那一列變**淺綠色**、「已盤」出現 ✔。
4. 選單「完成盤點（存入盤點紀錄）」→ 顯示「已填 1 列／共 58 列」→ 選「留在盤點表，下次繼續盤」→ 按「存入盤點紀錄」。
5. 跳出「已存入 1 筆盤點紀錄…盤點表還有 57 列沒填，已保留」。
6. 到「盤點紀錄」最下面，看到剛才那一筆；到「品項」找那個品項，「最新盤點日期」「最新數量」已更新。
7. **試用完請把那一筆刪掉**：到「盤點紀錄」最後一列，右鍵列號 →「刪除列」，再從選單執行「重新計算最新數量」。

### 平常怎麼用

| 情況 | 做法 |
|---|---|
| 期初／期中／期末盤點 | 「產生盤點表」選範圍（例：教室「化學準備室」）→ 逐列填「本次數量」→「完成盤點」 |
| 分好幾天盤 | 每天填一部分，做完就「完成盤點」選「留在盤點表」；已存的列會移走，沒填的留著 |
| 大部分沒變動 | 只填有變動的，「完成盤點」選「沿用上次數量一起存」 |
| 數量有文字 | 「本次數量」可以直接打「3箱+5串」「100g*2+50g」，系統會自己取數字，原文照樣列印 |
| 數字和說明分開 | 「本次數量」打 8、「本次說明」打「1.5粉狀 6.5固體顆粒」 |
| 填錯了已經存了 | 同一天重新盤點再存一次，會自動覆蓋；或直接改「盤點紀錄」後執行「重新計算最新數量」 |
| 上次說明寫「（上次為各處合計）」 | 這個品項改成分處盤點了，上次只有總數；這次請各處分別填 |

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 「這個範圍沒有使用中的品項」 | 範圍選錯，或該區品項都設為「已淘汰」 |
| 「盤點表缺少欄位」 | 盤點表的標題被改了；重新「產生盤點表」即可 |
| 產生時提醒「還有 N 列未儲存」 | 先「完成盤點」把已填的存起來；確定不要了才勾「我確定要清除」 |

## 第 4 步：手機盤點網頁

**做什麼**：手機用瀏覽器開一個網址，就能選教室、櫃別逐項輸入數量（自動存進「盤點表」），也能查詢品項位置與最新數量。
「產生盤點表」「完成盤點」仍在電腦上按。

### 貼程式

1. 「擴充功能 → Apps Script」→「＋」→「指令碼」，名稱 `03_手機盤點`。
2. 刪掉 `function myFunction() { }`，貼上 `apps-script/03_手機盤點.gs` 全部內容，Ctrl+S。

### 部署成網頁應用程式（只做一次）

**部署**：把程式變成一個網址，讓手機可以開。

1. Apps Script 右上角藍色「**部署**」→「**新增部署作業**」。
2. 左邊「選取類型」旁的齒輪 ⚙ →「**網頁應用程式**」。
3. 填寫：
   - 說明：`手機盤點`
   - 執行身分：**我**（您的信箱）
   - 誰可以存取：**只有我自己**
4. 按「部署」。如果要求授權，照第 2 步的方式按「允許」。
5. 出現「網頁應用程式」網址（`https://script.google.com/macros/s/……/exec`），按「**複製**」。
6. 回試算表「設定」分頁，把網址貼到「**手機網頁網址**」右邊那格（B 欄）。

### 確認成功

1. 電腦：先在試算表「產生盤點表」（例如清單分區「科學館共用」，只有 4 列，好測試）。
2. 電腦瀏覽器開剛才的網址 → 看到「盤點／查詢」兩個分頁、4 張卡片。
3. 在第一張卡片輸入數字、按 Enter → 出現「✔ 已存」→ 回試算表「盤點表」，那一列的「本次數量」已經有數字。
4. 手機：試算表選單「🧪 實驗室管理 → **開啟手機盤點網址**」→ 用手機相機掃畫面上的 QR code → 用瀏覽器開啟。
5. 手機瀏覽器選單 →「**加到主畫面**」（iPhone Safari：分享 ⬆ →「加入主畫面」），之後像 App 一樣點開。
6. 試用完：回電腦「完成盤點」存起來，或到「盤點紀錄」刪掉試用的列（見第 3 步）。

### 手機怎麼用

| 按鈕 | 作用 |
|---|---|
| 上方兩個下拉選單 | 選教室、櫃別 |
| 只看還沒盤的 | 勾起來，已盤的卡片會藏起來 |
| 大輸入框 | 打數量，按 Enter 或點別處就自動存，並跳到下一項 |
| ＝上次 | 數量和上次一樣時按這個，一鍵存好 |
| 說明 | 打「3箱+5串」這類文字 |
| 卡片左邊顏色 | 黃色＝還沒盤，綠色＝已盤 |
| ⚠ 沒存到 | 通常是網路斷了，點那行字重試 |
| 重新整理 | 電腦上重新產生盤點表後，手機要按這個 |

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 手機開網址出現「很抱歉，目前無法開啟這個檔案」 | 手機瀏覽器同時登入了好幾個 Google 帳號（Google 的已知問題）。改用只登入這個帳號的瀏覽器，或先登出其他帳號 |
| 要求登入 | 登入存放試算表的那個 Google 帳號 |
| 「目前沒有盤點表」 | 先在電腦「產生盤點表」，手機按「重新整理」 |
| 選單「開啟手機盤點網址」說網址不正確 | 「設定」的手機網頁網址要貼結尾是 `/exec` 的那個 |

### ⚠ 日後更新程式要重新部署

之後只要改了任何一個 `.gs` 檔，手機網頁**不會自動更新**，要：
「部署」→「**管理部署作業**」→ 選「手機盤點」→ 右上 ✏️ 編輯 →「版本」選「**新版本**」→「部署」。
網址不會變，手機不用重新加到主畫面。

## 第 5 步：列印報表

**做什麼**：選單多出「列印藥品清單」「列印器材耗材清單」。會在試算表裡開一個大的「列印預覽」對話框，A4 直式、每頁重複表頭、每頁頁尾有核章欄，可直接列印或另存 PDF。

### 貼程式

1. 「擴充功能 → Apps Script」。
   **換掉 `01_基礎`**（選單多了「列印申報清單」）：點它，Ctrl+A 刪除，貼上新版，Ctrl+S。
2. **換掉 `03_手機盤點`**：點它，Ctrl+A 全選刪除，貼上新版 `apps-script/03_手機盤點.gs`，Ctrl+S。
   （這次加了一個「轉接口」，以後的列印頁都靠它，之後不用再改這個檔案。）
3. 「＋」→「指令碼」，名稱 `04_列印`，刪掉 `function myFunction() { }`，貼上 `apps-script/04_列印.gs`，Ctrl+S。
4. 列印是在試算表裡的對話框開啟，**不需要重新部署**（但手機網頁若要用到新程式，仍依第 4 步重新部署）。

### 確認成功

1. 回試算表按 F5，選單「🧪 實驗室管理 → **列印藥品清單**」→「開啟列印頁」。
2. 出現「列印預覽」對話框（約 5～10 秒），上方有黃色工具列和「🖨 列印」按鈕。
3. 按「🖨 列印」→ 右邊預覽應該是 **8 頁左右**，每頁上方都有「臺北市立中山女子高級中學／化學與生物實驗室藥品清單／115學年度第1學期／更新日期」和欄位名稱，每頁下方都有核章欄和頁碼。
4. 列印設定：
   - 目的地：印表機，或「另存為 PDF」
   - 紙張大小：A4；版面配置：直向
   - 「更多設定」→ **取消勾選「頁首和頁尾」**（不然會印出網址和日期）、**勾選「背景圖形」**（欄位名稱的灰底）
5. 「列印器材耗材清單」→ 勾選要印的分區 →「開啟列印頁」，每個分區從新的一頁開始。

### 列印內容說明

| 清單 | 欄位 |
|---|---|
| 藥品清單 | 序號、中文名稱、化學式、教室、存放位置（櫃）、存放位置（排序）、最近 4 次盤點數量、備註 |
| 器材耗材清單（一般） | 序、存放位置、品項、單位、最近 1 次數量、備註 |
| 生物器材、生物耗材（分處） | 序、品項名稱、單位、各存放處數量、總數量、備註 |

- **序號**依櫃別與排序位置自動編，不用自己維護；「已淘汰」不印；「自己筆記」不印。
- **數量**：有「數量說明」的印說明（例：3箱+5串），沒有就印數字。
- **更新日期**：這份清單裡最近一次盤點的日期。

### 期初／期末申報：「列印申報清單（期初／期末）」

每學期期初、期末申報時用這個，**每個品項只印一欄數量**（不印歷史）。

1. 選單「🧪 實驗室管理 →**列印申報清單（期初／期末）**」。
2. 「申報哪一次盤點」：選那次盤點（例：115.08.26　115-1期初）。
   - 那次盤點沒點到的品項，會印「在那之前最近一次」的數字。
3. 「學期標示」自動帶出「115學年度第1學期期初」，印在每頁表頭，可以修改。
4. 勾選要印的清單，順序比照簽文：科學館共用 → 藥品清單 → 生物（器材、耗材、顯微鏡觀察、解剖用具、實驗套組）→ 化學（器材區、綜合區、化3後櫃、化1化2）。永久玻片預設不勾。
5. 「開啟列印頁」→「🖨 列印」。
6. 列印頁上方工具列有「📄 **簽稿文字**」，點開後按「複製簽稿文字」，貼到公文系統（學期會自動帶入，可再修改）。這段文字不會印出來。

> 盤點名稱要寫對（例：115-1期末），學期標示才會自動帶對；寫錯也可以在對話框直接改。

### 可以在「設定」調整的

| 設定 | 作用 |
|---|---|
| 學年度學期 | 表頭「115學年度第1學期」，每學期開始改一次（例：115-2） |
| 核章欄 | 用逗號分隔，例：實驗室管理員,設備組長,主任,校長 |
| 藥品清單列印盤點次數 | 預設 4 |
| 器材耗材清單列印盤點次數 | 預設 1（比照舊檔）；改成 3 就印最近 3 次 |
| 清單分區表的列印標題、副標題、存放地點 | 各分區表頭的文字 |
| 清單分區表的分處欄位 | 分處清單的欄位，例：生1、生2 或 木櫃、防潮櫃、冰箱 |

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 出現「很抱歉，目前無法開啟這個檔案」 | 舊版是開新分頁，瀏覽器登入多個 Google 帳號時會這樣；請換成新版 `04_列印`、`05_標示`（改在對話框開啟） |
| 「找不到列印功能」 | `04_列印`（或第 6 步的 `05_標示`）沒有貼上或沒有儲存 |
| 預覽只有 1 頁、內容被切掉 | 請用對話框上方的「🖨 列印」按鈕，不要用 Ctrl+P |
| 印出來有網址 | 列印設定「更多設定」取消「頁首和頁尾」 |
| 欄位名稱沒有灰底 | 列印設定勾選「背景圖形」 |

## 第 6 步：藥品櫃標示

**做什麼**：選單「列印藥品櫃標示」，依「品項」的櫃別與排序位置自動產生櫃內、櫃外標示，每格印品名與化學式。

### 貼程式

1. 「擴充功能 → Apps Script」→「＋」→「指令碼」，名稱 `05_標示`，刪掉 `function myFunction() { }`，貼上 `apps-script/05_標示.gs`，Ctrl+S。
2. 不需要重新部署（列印在試算表的對話框開啟）。

### 確認成功

1. 回試算表 F5 → 選單「🧪 實驗室管理 →**列印藥品櫃標示**」。
2. 選「櫃外標示」、全選 →「開啟列印頁」→「🖨 列印」。
3. 預覽 **8 頁**（A、B、C、D、E、F、2-B、2-D 各一頁），**橫向**；右上角有教室（F 櫃是化學實驗室一）與更新日期。
4. 再試「櫃內標示」：直向，約 4 頁，櫃子接著印。

### 排版規則

| 情況 | 標示上 |
|---|---|
| 排序位置 3-2 | 第 3 排第 2 格，格子左上角小字「3-2」 |
| 空號（例：E 櫃 5-8 甲醛已淘汰） | 空白格，後面的位置不會往前擠 |
| 「3-2旁」 | 排在 3-2 後面 |
| 「3-2/大冰箱」 | 格子下方加註「大冰箱」 |
| 同一位置兩個（例：順／反丁烯二酸都在 4-5） | 並排兩格 |
| 一排超過 10 個（例：E 櫃第 1、5 排） | 接到下一行「第1排（續）」 |
| 化學式的數字 | 自動變下標（NH₄Cl） |
| 教室和這個櫃子不同的品項（例：放生物準備室冰箱的抗A血清） | 不印在櫃子標示上 |
| 已淘汰 | 不印 |

藥品移位時：改「品項」的櫃別、排序位置 → 重新列印那一櫃即可。

## 第 7 步：需補充清單、查詢

**做什麼**：「需補充清單」自動列出低於安全存量的品項；「查詢」工作表輸入條件即時篩選；選單「列印需補充清單」。

### 貼程式

1. 「擴充功能 → Apps Script」→「＋」→「指令碼」，名稱 `06_補充查詢`，刪掉 `function myFunction() { }`，貼上 `apps-script/06_補充查詢.gs`，Ctrl+S。
2. 回試算表 F5 → 選單「🧪 實驗室管理 →**更新需補充清單**」（第一次會放好兩張表的公式，之後會自己更新，不用再按）。

### 確認成功

1. 到「品項」隨便找一個品項（例：氟化鈉，最新數量 1），在「安全存量」填 **2**。
2. 到「需補充清單」→ 氟化鈉出現，「建議補充」＝ 1。
3. 把安全存量改回空白 → 氟化鈉從需補充清單消失。
4. 到「查詢」→ 黃色格子第一格打「燒杯」→ 下方列出所有燒杯；「教室」選「生物實驗室一」→ 只剩生物實驗室的燒杯。
5. 選單「列印需補充清單」→ 出現列印預覽。

### 使用說明

| 工作表 | 怎麼用 |
|---|---|
| 需補充清單 | 不用操作，盤點完成後自動更新。條件：有填安全存量、最新數量低於安全存量、不是已淘汰 |
| 查詢 | 第 4 列黃色格子輸入條件（空白＝不限）：關鍵字（品名、化學式、編號都找）、類別、科別、清單分區、教室（包含分處存放）、櫃別、狀態（預設「使用中」，清空就連已淘汰一起找） |

- 這兩張表的內容是公式算出來的，**不要在下面的格子打字**（會讓公式出錯）。
- 手機 Google 試算表 App 也能看；手機網頁的「查詢」分頁也可以查。
- 萬一公式被刪掉：選單「更新需補充清單」會自動重建。
