# 安裝步驟（依序完成；日後交接可照此重建）

## 第 1 步：建立試算表

1. 把 `data/新系統初始資料.xlsx` 上傳到 Google 雲端硬碟。
2. 在檔案上按右鍵 →「開啟工具 → Google 試算表」。
3. 上方「檔案 → 儲存為 Google 試算表」，之後都用這份。
4. 改名為「實驗室藥品器材管理系統」。
5. **檢查時區**：「檔案 → 設定」→「時區」選 **(GMT+08:00) 台北**，按「儲存設定」。
   （時區不對，日期可能差一天。）

---

## 第 2 步：貼上基礎程式

**做什麼**：試算表上方出現「🧪 實驗室管理」選單；新增品項自動給編號；可重新計算最新數量；套用下拉選單與格式。

### 貼程式

1. 在試算表上方點「**擴充功能 → Apps Script**」，會開新分頁（Apps Script 編輯器）。
2. 左上角專案名稱「未命名的專案」點一下，改成「實驗室管理系統」。
3. 左邊「檔案」下有一個 `程式碼.gs`（或 `Code.gs`）。點它右邊的「⋮ → 重新命名」，改成 `01_基礎`。
4. 把右邊編輯區原有的 `function myFunction() { }` **全部刪掉**。
5. 打開 `apps-script/01_基礎.gs`，**全部複製**（Ctrl+A、Ctrl+C），貼到編輯區（Ctrl+V）。
6. 按上方 💾「儲存專案」（或 Ctrl+S）。

### 第一次執行（授權）

1. 編輯區上方有個下拉選單（寫著某個函式名稱），選 **`setupSheets`**，按「▶ 執行」。
2. 跳出「需要授權」→「審查權限」→ 選您的 Google 帳號。
3. 出現「Google 尚未驗證這個應用程式」→ 點左下「**進階**」→「**前往「實驗室管理系統」(不安全)**」→「**允許**」。
   - 這是您自己寫、只存取這份試算表的程式，所以 Google 會這樣提醒，可以放心。
4. 下方「執行記錄」出現「**執行完畢**」就完成了。

### 確認成功

1. 回到試算表分頁，按 F5 重新整理。
2. 上方出現「**🧪 實驗室管理**」選單（載入要幾秒鐘），目前裡面有 3 項（之後每完成一步會自動多出新功能）：
   - 重新計算最新數量
   - 補上缺少的編號
   - 套用工作表格式與下拉選單
3. 點「重新計算最新數量」，右下角出現「已更新 723 個品項的最新數量」。
4. 到「品項」最下面新增一列測試：類別選「藥品」、品名打「測試」→ 編號欄自動出現「藥0245」、狀態自動變「使用中」。確認後把這一列刪掉（右鍵列號 → 刪除列）。

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 看不到選單 | 重新整理試算表；等 5 秒；還是沒有，回 Apps Script 確認已儲存 |
| 「找不到工作表『○○』」 | 分頁名稱被改過，改回原名 |
| 「缺少欄位：○○」 | 第一列標題被改過或刪掉，改回原名 |
| 新增品項沒有自動編號 | 要先選「類別」再打品名（或反過來都可以，兩個都有才會編）；或從選單執行「補上缺少的編號」 |

## 第 3 步：盤點功能（電腦版）

**做什麼**：選單多出「產生盤點表」「完成盤點（存入盤點紀錄）」。

### 貼程式

1. 試算表「擴充功能 → Apps Script」。
2. 左邊「檔案」旁的「＋」→「指令碼」，名稱打 `02_盤點`（會自動變成 `02_盤點.gs`）。
3. 把新檔案裡原有的 `function myFunction() { }` 刪掉。
4. 複製 `apps-script/02_盤點.gs` 全部內容貼上，Ctrl+S 儲存。
5. **`01_基礎` 不要動**，兩個檔案要同時存在。

### 第一次執行

1. 回到試算表，按 F5 重新整理。
2. 選單「🧪 實驗室管理 → 產生盤點表」。
3. 第一次會再要求授權一次（因為新增了「對話框」功能），照第 2 步的方式按「允許」。授權完再點一次「產生盤點表」。

### 試用（確認成功）

1. 「產生盤點表」→ 盤點範圍選「清單分區」「生物器材」→ 日期、名稱用預設 → 按「產生盤點表」。
2. 自動跳到「盤點表」分頁，看到：
   - 每個品項分成「生物實驗室一」「生物實驗室二」兩列
   - 「上次日期」115.08.26、「上次數量」有數字
   - 「本次數量」「本次說明」兩欄是**黃色**
3. 在第一列「本次數量」打個數字 → 那一列變**淺綠色**、「已盤」出現 ✔。
4. 選單「完成盤點（存入盤點紀錄）」→ 顯示「已填 1 列／共 58 列」→ 選「留在盤點表，下次繼續盤」→ 按「存入盤點紀錄」。
5. 跳出「已存入 1 筆盤點紀錄…盤點表還有 57 列沒填，已保留」。
6. 到「盤點紀錄」最下面，看到剛才那一筆；到「品項」找那個品項，「最新盤點日期」「最新數量」已更新。
7. **試用完請把那一筆刪掉**：到「盤點紀錄」最後一列，右鍵列號 →「刪除列」，再從選單執行「重新計算最新數量」。

### 平常怎麼用

| 情況 | 做法 |
|---|---|
| 期初／期中／期末盤點 | 「產生盤點表」選範圍（例：教室「化學準備室」）→ 逐列填「本次數量」→「完成盤點」 |
| 分好幾天盤 | 每天填一部分，做完就「完成盤點」選「留在盤點表」；已存的列會移走，沒填的留著 |
| 大部分沒變動 | 只填有變動的，「完成盤點」選「沿用上次數量一起存」 |
| 數量有文字 | 「本次數量」可以直接打「3箱+5串」「100g*2+50g」，系統會自己取數字，原文照樣列印 |
| 數字和說明分開 | 「本次數量」打 8、「本次說明」打「1.5粉狀 6.5固體顆粒」 |
| 填錯了已經存了 | 同一天重新盤點再存一次，會自動覆蓋；或直接改「盤點紀錄」後執行「重新計算最新數量」 |
| 上次說明寫「（上次為各處合計）」 | 這個品項改成分處盤點了，上次只有總數；這次請各處分別填 |

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 「這個範圍沒有使用中的品項」 | 範圍選錯，或該區品項都設為「已淘汰」 |
| 「盤點表缺少欄位」 | 盤點表的標題被改了；重新「產生盤點表」即可 |
| 產生時提醒「還有 N 列未儲存」 | 先「完成盤點」把已填的存起來；確定不要了才勾「我確定要清除」 |

## 第 4 步：手機盤點網頁

**做什麼**：手機用瀏覽器開一個網址，就能選教室、櫃別逐項輸入數量（自動存進「盤點表」），也能查詢品項位置與最新數量。
「產生盤點表」「完成盤點」仍在電腦上按。

### 貼程式

1. 「擴充功能 → Apps Script」→「＋」→「指令碼」，名稱 `03_手機盤點`。
2. 刪掉 `function myFunction() { }`，貼上 `apps-script/03_手機盤點.gs` 全部內容，Ctrl+S。

### 部署成網頁應用程式（只做一次）

**部署**：把程式變成一個網址，讓手機可以開。

1. Apps Script 右上角藍色「**部署**」→「**新增部署作業**」。
2. 左邊「選取類型」旁的齒輪 ⚙ →「**網頁應用程式**」。
3. 填寫：
   - 說明：`手機盤點`
   - 執行身分：**我**（您的信箱）
   - 誰可以存取：**只有我自己**
4. 按「部署」。如果要求授權，照第 2 步的方式按「允許」。
5. 出現「網頁應用程式」網址（`https://script.google.com/macros/s/……/exec`），按「**複製**」。
6. 回試算表「設定」分頁，把網址貼到「**手機網頁網址**」右邊那格（B 欄）。

### 確認成功

1. 電腦：先在試算表「產生盤點表」（例如清單分區「科學館共用」，只有 4 列，好測試）。
2. 電腦瀏覽器開剛才的網址 → 看到「盤點／查詢」兩個分頁、4 張卡片。
3. 在第一張卡片輸入數字、按 Enter → 出現「✔ 已存」→ 回試算表「盤點表」，那一列的「本次數量」已經有數字。
4. 手機：試算表選單「🧪 實驗室管理 → **開啟手機盤點網址**」→ 用手機相機掃畫面上的 QR code → 用瀏覽器開啟。
5. 手機瀏覽器選單 →「**加到主畫面**」（iPhone Safari：分享 ⬆ →「加入主畫面」），之後像 App 一樣點開。
6. 試用完：回電腦「完成盤點」存起來，或到「盤點紀錄」刪掉試用的列（見第 3 步）。

### 手機怎麼用

| 按鈕 | 作用 |
|---|---|
| 上方兩個下拉選單 | 選教室、櫃別 |
| 只看還沒盤的 | 勾起來，已盤的卡片會藏起來 |
| 大輸入框 | 打數量，按 Enter 或點別處就自動存，並跳到下一項 |
| ＝上次 | 數量和上次一樣時按這個，一鍵存好 |
| 說明 | 打「3箱+5串」這類文字 |
| 卡片左邊顏色 | 黃色＝還沒盤，綠色＝已盤 |
| ⚠ 沒存到 | 通常是網路斷了，點那行字重試 |
| 重新整理 | 電腦上重新產生盤點表後，手機要按這個 |

### 出錯怎麼辦

| 狀況 | 處理 |
|---|---|
| 手機開網址出現「很抱歉，目前無法開啟這個檔案」 | 手機瀏覽器同時登入了好幾個 Google 帳號（Google 的已知問題）。改用只登入這個帳號的瀏覽器，或先登出其他帳號 |
| 要求登入 | 登入存放試算表的那個 Google 帳號 |
| 「目前沒有盤點表」 | 先在電腦「產生盤點表」，手機按「重新整理」 |
| 選單「開啟手機盤點網址」說網址不正確 | 「設定」的手機網頁網址要貼結尾是 `/exec` 的那個 |

### ⚠ 日後更新程式要重新部署

之後只要改了任何一個 `.gs` 檔，手機網頁**不會自動更新**，要：
「部署」→「**管理部署作業**」→ 選「手機盤點」→ 右上 ✏️ 編輯 →「版本」選「**新版本**」→「部署」。
網址不會變，手機不用重新加到主畫面。
