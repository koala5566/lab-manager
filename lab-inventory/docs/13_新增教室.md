# 新增上課教室：多功能教室三、四、五、階梯教室

> 約 5 分鐘。

## 一、在「設定」加教室（最重要，一定要做）

- [ ] **1.** 打開試算表「**設定**」分頁 → 往右捲找到「**上課教室**」那一欄（現在有化學實驗室一～生物實驗室三六間）
- [ ] **2.** 在生物實驗室三下面接著打（一格一個）：
  - 多功能教室三
  - 多功能教室四
  - 多功能教室五
  - 階梯教室
- [ ] **3.** 「🔧 維護 → 首頁、美化與資料保護（一次設定）」（「實驗排程」的教室下拉選單會多這四間）

做完這三步，登記使用、使用一覽、門口海報、本週課表、網頁都會出現這四間。

## 二、換程式（把「六間」字樣改掉、網頁上的簡稱）

| ✅ | 檔案 | 做法 | 貼完最後一行的行號 |
|---|---|---|---|
| ☐ | `01_基礎` | 換掉 | 430 |
| ☐ | `07_安全美化` | 換掉 | 423 |
| ☐ | `12_實驗室使用` | 換掉 | 799 |
| ☐ | `15_今日與便利` | 換掉 | 369 |
| ☐ | `16_網頁工作台` | 換掉 | 1238 |

- [ ] 「部署 → 管理部署作業」→ ✏️ →「版本：新版本」→「部署」
- [ ] 回試算表 F5 → 再按一次「🔧 維護 → 首頁、美化與資料保護（一次設定）」（首頁的說明文字更新）

改了什麼：
- 選單「六間實驗室使用一覽」→「實驗室使用一覽」；列印選「全部」
- 網頁、首頁課表的簡稱：多功能教室三 →「多功三」、階梯教室 →「階梯」（格子放得下）
- 網頁電腦版「各實驗室・現在」會自動排成多欄

## 之後還要加教室
只要做第一部分（在「設定」的「上課教室」加一格），不用改程式。
