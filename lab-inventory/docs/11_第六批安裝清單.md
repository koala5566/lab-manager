## 三、試用

- [ ] **3. 補實驗名稱**：「🗓 實驗室使用 → ✏️ 補實驗名稱（一次填好幾堂）」
  - 上面選期間、實驗室、老師 → 下面列出還沒填名稱的實驗課（預設全勾）
  - 不要的取消勾選 → 最下面填「實驗名稱」（可從套組選或直接打）、組數可空白 →「套用到勾選的」✅ 顯示「已填 N 堂」
- [ ] **4. 點課**：「🗓 實驗室使用 → 六間實驗室使用一覽」→ **點任一堂課**
  - ✅ 跳出這堂課的詳細
  - 實驗課可以直接填實驗名稱（勾「同一週、同一間、同一位老師…也一起填」就一次補好那位老師那週的課）
  - 下面「這堂課的準備事項」可以直接新增（日期、實驗室、節次、班級、老師已經填好）
  - 實驗名稱填好的，有「🖨 這天的器材準備單」
  - 有待準備事項的課，格子上會顯示 📝 和數量
- [ ] **5. 手機**：開盤點網頁 ✅ 一開就是「**今天**」分頁：今天和下一個上課日的課（現在這節紅框）、待準備事項（可打勾）、需補充幾項
