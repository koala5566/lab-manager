## 二、發現的問題（依嚴重程度）

### 🔴 建議上線前修正

**H1　到貨入庫可能重複加庫存，或更新到錯的那一列**
- 現況：「到貨入庫」用「第幾列」找請購項目，而且不檢查那一項是不是已經「已到貨」。
- 會發生的情況：
  - 對話框開著時，有人在「請購清單」刪了一列，列號就錯了，會把**別的東西**標成到貨，並加到**別的品項**的庫存。
  - 同一項被送出兩次（例如網路慢、重開舊的對話框），庫存會**加兩次**。
- 「歸還登記」也是用列號，一樣可能標到別筆（不影響庫存）。
- 建議：先比對品名＋狀態；已經「已到貨」的就跳過。

**H2　網頁「課表」在平板橫放、筆電上會左右超出畫面**
- 1024 寬超出 394px、1280 寬超出 138px，要左右滑才看得到搜尋框和右邊。
- 原因：教室按鈕列太長，把整個版面撐寬。已驗證改一行版面設定就能修好（7 種尺寸全部正常）。

### 🟠 建議修正

**M1　6 個寫資料的功能沒有「排隊鎖」**
- 登記使用、新增請購、到貨入庫、借出、歸還、新增實驗排程。
- 手機和電腦**剛好同時**存檔時，可能寫到同一列、互相蓋掉。只有您一個人用，機率很低，但手機、電腦都開著時有可能發生。
- 其他功能（盤點、準備事項、補名稱、匯入、新增品項、異動）都已經有鎖。

**M2　開頭是 `=`、`+`、`@` 的文字會被試算表當成公式**
- 例如準備事項打「+886 分機」「=A1」，試算表會顯示 `#ERROR!` 或變成公式。
- 影響：準備事項、請購、借用、備註，還有匯入老師的 Excel。
- 風險：只有您自己輸入，不會被別人利用，但打到的時候會很困惑。建議存檔時自動在前面加 `'`（試算表的「當文字」記號）。

**M3　全形數字的節次讀不到**
- 在試算表手打「３」「３-４」（全形），課表上看不到那一筆。
- 用對話框或網頁登記不會有這個問題（都是半形）。建議讀取時自動把全形轉半形。

**M4　首頁「今天／下一個上課日」課表公式要您確認**
- 這是 Google 試算表公式，我這邊沒辦法在真的試算表跑，請看首頁有沒有正常顯示。

**M5　改教室名稱後，舊的登記會對不起來**
- 例如把「化學實驗室一」改名成「化一實驗室」，之前登記的還是舊名稱，單日、整週課表就看不到。
- 建議：教室名稱定了就不要改；真的要改，要在「實驗排程」用「尋找與取代」一起改。之後可以做一個「教室改名」工具。

**M6　匯入老師課表時會整張重寫「實驗排程」**
- 匯入的那幾秒內，如果同時在改「實驗排程」，改的內容可能不見。
- 您在某一列手動加的底色，可能因為排序跑到別列。
- 建議：匯入時不要同時編輯；另外可改成只更動匯入的那幾列。

### 🟡 小問題（可以之後再說）

| # | 問題 | 影響 |
|---|---|---|
| L1 | 日期打「2026/02/30」這種不存在的日子不會被擋 | 會變成 3 月初 |
| L2 | 登記使用沒檢查節次範圍 | 只有直接呼叫程式才會發生，畫面操作不會 |
| L3 | iOS 16.2 以前的舊 iPad／iPhone，課表格子沒有底色 | 文字看得到，只是沒顏色 |
| L4 | 320 寬的小手機（iPhone SE 一代），「今天」頁多出 12px | 幾乎看不出來 |
| L5 | 「設定」裡的節次名稱、顏色沒有特別處理特殊符號 | 只有您自己能改，風險極低 |
| L6 | 很多人同時存檔、等太久時，錯誤訊息是英文（Lock timeout） | 很少發生 |
| L7 | 網頁第一次開約 3～6 秒（要讀 722 個品項、算需補充） | 可以加快取，縮短到 1～2 秒 |

### ✅ 確認沒問題的
- XSS：所有列印頁、網頁畫面都有跳脫，惡意字串不會被執行。
- 權限：網頁「只有我自己」＋試算表「限制」，別人拿到網址也開不了，也不能呼叫任何程式。
- 刪列之後才存：盤點（編號＋存放處）、準備事項（ID）、補實驗名稱（日期＋教室＋節次＋班級）都能正確找到，找不到會提示中文訊息。
- 重複匯入老師課表不會重複（127 筆 → 127 筆）；已補的實驗名稱會保留。
- 節次「3-4」被試算表轉成日期的問題已修好（上一批）。

| 優先 | 功能 | 說明 | 難度 |

| ⭐⭐⭐ | **網頁加速（快取）** | 第一次開從 3～6 秒縮短到 1～2 秒 | 低 |

| ⭐⭐⭐ | **藥品有效期限、開封日期** | 品項加「有效期限」，到期前 30 天提醒；過期的標紅，盤點時提醒要報廢 | 中 |

| ⭐ | **手機相機掃條碼盤點** | Android Chrome 可以用相機掃藥品原廠條碼找品項（iPhone 支援度差） | 中 |
