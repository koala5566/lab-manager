# 第五批安裝清單：準備事項（待辦）

老師口頭交代、寫便條紙要準備的東西，自己輸入成待辦清單；電腦、手機都能新增和打勾。

> 約 5 分鐘。照順序做，做完打勾 ✅。

## 一、貼程式（4 個檔案）

「擴充功能 → Apps Script」。
**換掉**：點檔名 → Ctrl+A → Delete → Ctrl+V → Ctrl+S
**新增**：「＋」→「指令碼」→ 打檔名 → 刪掉 `function myFunction() { }` → 貼上 → Ctrl+S

| ✅ | 檔案 | 做法 | 貼完最後一行的行號 |
|---|---|---|---|
| ☐ | `01_基礎` | 換掉 | 429 |
| ☐ | `03_手機盤點` | 換掉 | 431 |
| ☐ | `07_安全美化` | 換掉 | 381 |
| ☐ | `14_準備事項` | 新增 | 396 |

- [ ] 左邊總共 **14 個檔案**

## 二、重新部署、一次設定

- [ ] **1.** 「部署 → 管理部署作業」→「手機盤點」→ ✏️ →「版本：**新版本**」→「部署」
- [ ] **2.** 回試算表按 F5 →「🔧 維護 → 首頁、美化與資料保護（一次設定）」
      ✅ 第一行有「準備事項工作表」；下面多了黃色「**準備事項**」分頁；首頁第二排多一張「待準備事項」卡片

## 三、試用

- [ ] **3.** 「🗓 實驗室使用 → 📝 新增準備事項（老師交代的）」
  - 「哪天要用」選明天 →「對到當天的課」可以選一堂（實驗室、節次、班級、老師會自動填好），不選也可以
  - 「要準備的東西」打「燒杯」→ 下面跳出品項 → 點一個（會顯示存放位置和庫存）→ 數量打 5
  - 按「＋ 再一樣」→ 打「測試」（品項沒有的東西直接打就好）→ 數量 1
  - 按「儲存」✅ 綠字「已新增 2 項準備事項」，下面清單出現這兩項
- [ ] **4.** 在清單上把「燒杯」打勾 ✅ 移到「最近完成」；在「最近完成」按「已歸還」
- [ ] **5.** 「🗓 實驗室使用 → 列印準備事項」→ 開啟列印頁 ✅ 有打勾欄的清單
- [ ] **6.** 手機開盤點網頁 → 上面多了「**待辦**」分頁 → 看得到剛剛的事項，也可以按「＋ 新增」
- [ ] **7.** 試完：「測試」那項按「取消」→ 再按一次「確定取消？」
