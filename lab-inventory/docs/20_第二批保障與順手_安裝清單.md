## 二、改了什麼、怎麼試

| 代號 | 現在 | 試試看 |
|---|---|---|
| **A5** 盤點數量怪怪的 | 比上次多 5 倍以上、1000 以上、負數 → 按鈕變橘色「比上次多很多（1.5 → 100）？再按一次」。改了數字要重新確認；正常數字一次就存 | 盤點時打 1000 按存 |
| **A6** 手機返回鍵 | 先關掉彈出的視窗 → 再回上一個分頁；新增打到一半按返回，會問「還沒儲存」 | 打開一堂課 → 按手機的返回鍵 |
| **D5** 修改紀錄 | 直接在試算表改「品項、盤點紀錄、實驗套組、設定、請購清單、借用紀錄、實驗排程、準備事項」時，「**修改紀錄**」工作表會記下：時間、誰、哪一格、欄位、哪個品項、原本、改成。新的在最上面；一次貼上很多格記成一筆摘要；最多留 5000 筆（超過自動刪掉最舊的） | 在「品項」改一個數量 → 看「修改紀錄」 |
| **D7** 永久備份 | 「🔧 維護 → 📦 **學期末永久備份**」：檔名「永久備份_…」，不會被自動刪除。**完成盤點**的自動備份也改成永久的。每週的一般備份照樣只留 10 份 | 按一次，到雲端硬碟「實驗室管理備份」資料夾看 |
| **C1** 一堂課全部打勾 | 點課 → 準備事項有 2 項以上待準備時，右邊有「**全部打勾（N）**」，按錯可以復原 | 點一堂有準備事項的課 |
| **C2** 待辦依課分組 | 待辦清單裡，同一天、同一堂課（同教室、同節、同班）有 2 項以上的會收成一組：組名「第3節 化一 二業　3 項」，點組名可以**收合**，右邊「**全部打勾**」 | 用「一鍵產生準備事項」產生一堂 → 看待辦 |

## 小提醒

- 「修改紀錄」只記**人直接在試算表上改的**；網頁、對話框存的資料本來就有自己的紀錄（登錄時間、完成時間），不會重複記。
- 「誰」那欄：學校帳號會顯示信箱；如果是 Google 不給的情況會是空白。
- 返回鍵用的是 Apps Script 提供的 `google.script.history`。如果某支手機的返回鍵還是直接離開，跟我說一聲。
- 永久備份會一直累積，大概一學期 2～3 份（完成盤點＋學期末），很久以後雲端硬碟空間不夠時，可以手動刪最舊的。
