## 二、開啟每天早上 email 提醒

- [ ] **1.** 回試算表按 F5 →「🧪 實驗室管理 → 🔧 維護 → **📧 每天早上 email 提醒（設定）**」
- [ ] **2.** 第一次會要求**授權**（因為多了「寄信」的權限）：選自己的帳號 →「進階」→「前往（不安全）」→「允許」
      > 「不安全」是 Google 對所有自己寫的程式都會顯示的警告，這是你自己的程式，可以放心。
      > 授權完要再點一次選單。
- [ ] **3.** 收件人預設是你自己；要同時寄給同仁，用逗號分開，最多 10 個
- [ ] **4.** 按「**先寄一封測試信**」→ 到信箱看看（第一次可能在「促銷內容」或「垃圾郵件」，標成「不是垃圾郵件」）
- [ ] **5.** 選幾點寄（5～9 點，預設 7 點，Google 會在前後約 15 分鐘內寄）→「**儲存並開啟**」
      ✅ 顯示「已開啟：每天早上 7 點左右…」

信裡有（沒有的部分不會出現）：

| 區塊 | 內容 |
|---|---|
| 📅 今天的課 | 節次、時間、教室、班級、老師、實驗、組數 |
| ⚠ 過期還沒準備 | 日期已過、還是「待準備」的準備事項 |
| 📝 今天要準備／下一個上課日要準備 | 東西、數量、存放位置；庫存不夠的會標紅 |
| ⚠ 器材不夠 | 今天、下一個上課日的實驗，套組器材庫存不夠的 |
| ✏️ 還沒填實驗名稱 | 實驗課沒填名稱的（填了才能檢查器材） |
| 其他 | 借出中（逾期）、請購待處理、需補充 |
| 按鈕 | 打開網頁工作台 |

- 週六、週日不寄（設定可以勾「週末有登記課時也寄」）。
- 當天沒有任何事情也不寄（設定可以勾「沒事也寄」）。
- 整天登記「放假」、又沒有過期或今天要準備的，不寄。
- 要停止：同一個選單 →「**關閉提醒**」。

## 三、實驗套組一鍵產生準備事項

**網頁（一堂一堂）**
- [ ] **6.** 網頁 → 課表 → 點一堂**有實驗名稱、有對應實驗套組**的課
- [ ] **7.** 器材清單下面有「**一鍵產生準備事項**」→ 點下去
      ✅ 打開「新增準備事項」，套組的器材都帶好了：數量＝每組數量 × 組數、單位、備註「實驗套組：○○（N 組）」
- [ ] **8.** 不要的按 ✕、數量可以改、要先買的勾 🛒 →「儲存」
- [ ] **9.** 再點一次同一堂課的按鈕 ✅ 顯示「都已經在準備事項裡了」（不會重複）

**試算表（一次一段期間）**
- [ ] **10.**「🗓 實驗室使用 → **📝 依實驗套組產生準備事項（一段期間）**」
- [ ] **11.** 選日期（預設今天起一週，最多兩個月）→ 會先列出哪幾堂、各幾項 →「產生」
      > 只算「實驗課」「補做實驗」、實驗名稱有對應實驗套組、還沒歸還的課。已經有的不重複加。

## 四、網頁開啟加速（不用設定）

- [ ] **12.** 手機打開網頁兩次：
      ✅ 第一次跟以前一樣要等幾秒
      ✅ 第二次**馬上**出現畫面，上方有小提示「顯示 10/1 07:12 的資料，正在更新…」，1～3 秒後自動換成最新的、提示消失
- 沒有網路時，會顯示上次的資料，並提示「沒有連上網路」。
- 上次的資料存在**這台裝置的瀏覽器**裡。用公用電腦時，用完到「更多 → **清除這台裝置的暫存資料**」。
- 程式端也變快：開網頁時同一張工作表只讀一次（以前「設定」會被讀 9 次）。

## 之後怎麼用

- 每天早上看信就知道今天要做什麼，點信裡的按鈕直接打開網頁。
- 每週一（或排課後）用「依實驗套組產生準備事項」把這週的器材一次加進待辦，準備時打勾就好。
- 套組的器材要改，改「實驗套組」工作表就好，下次產生就是新的內容（已經產生的不會跟著變）。
